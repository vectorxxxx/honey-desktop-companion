# Security Policy

[简体中文](SECURITY.md) · **English**

## Supported versions

Security fixes target the latest stable release. Before reporting a vulnerability, please confirm that it is reproducible with the [Latest Release](https://github.com/vectorxxxx/honey-desktop-companion/releases/latest).

## Reporting a vulnerability

Please use the repository's [private vulnerability reporting](https://github.com/vectorxxxx/honey-desktop-companion/security/advisories/new). Do not disclose vulnerabilities in a public Issue or Discussion.

Include the following when possible:

- The affected Honey and Windows versions
- The impact and reproduction steps
- Sanitized logs, screenshots, or a minimal example
- Any mitigation you have already tried

Remove API keys, access tokens, local paths, databases, and other personal information before submitting. The maintainer will acknowledge the report as soon as practical and keep you informed until a fix is available.

## Security boundaries

Honey's AI features are disabled by default. Reports concerning credential protection, local data, startup integration, updates, and release integrity are especially welcome.
